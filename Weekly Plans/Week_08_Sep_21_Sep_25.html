📋 Daily Schedule

Monday (9/21)

  • Drill: TD 23 (Now includes newly added identities: double angle, sum/difference, half angle, power reducing)
  • Lesson Covered:
  • Lesson 4 – Intro to Applications of Trig Functions and Inverse Trig Functions
    • Review solving right triangles
    • 2 new triangle area formulas:
    • $SAS$ Formula: $\text{Area} = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$
    • Heron's Formula ($SSS$): $\text{Area} = \sqrt{s(s-a)(s-b)(s-c)}$ where $s = \frac{a+b+c}{2}$
  • Questions and review from Lessons 1 through 3
  • Practice Assignments:
  • Textbook p. 414: #19–24
  • Textbook p. 421–422: #27–33

    • Using the Law of Cosines to solve oblique triangles:
    • $a^2 = b^2 + c^2 - 2bc\cos A$
    • $b^2 = a^2 + c^2 - 2ac\cos B$
    • $c^2 = a^2 + b^2 - 2ab\cos C$

  • Graded Practice: Continue working on DeltaMath – Unit 3: Practice 2 (Due Sunday, 9/27 at 11:59 PM)

🎯 Success Criteria

By the end of this week, students will be able to:
1. Solve right triangles.
2. Find the area of triangles using 2 sides and the included angle ($SAS$).
3. Find the area of triangles using all 3 sides ($SSS$ / Heron’s formula).
4. Solve an oblique (non-right) triangle using the Law of Cosines.
