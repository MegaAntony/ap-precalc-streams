📐 Pillar 1: Complete Analytical Trigonometry Identity Vault (TD 35–40 / FD 11)
Memorize Cold for Tuesday's Quiz
1. Sum & Difference Formulas (Larson 5.4)

Memory Rule: "Sine mixes $\sin\cos$ and keeps the sign; Cosine groups $\cos\cos - \sin\sin$ and flips the sign."

$$\sin(u + v) = \sin u \cos v + \cos u \sin v$$ $$\sin(u - v) = \sin u \cos v - \cos u \sin v$$ $$\cos(u + v) = \cos u \cos v - \sin u \sin v$$ $$\cos(u - v) = \cos u \cos v + \sin u \sin v$$ $$\tan(u + v) = \frac{\tan u + \tan v}{1 - \tan u \tan v}, \qquad \tan(u - v) = \frac{\tan u - \tan v}{1 + \tan u \tan v}$$
2. Double-Angle Formulas (Larson 5.5)

Crucial: Know all three forms of $\cos(2u)$ so you can pick the one that matches your given info!

$$\sin(2u) = 2\sin u \cos u$$ $$\cos(2u) = \cos^2 u - \sin^2 u$$ $$\cos(2u) = 2\cos^2 u - 1$$ $$\cos(2u) = 1 - 2\sin^2 u$$ $$\tan(2u) = \frac{2\tan u}{1 - \tan^2 u}$$
3. Half-Angle Formulas (Larson 5.5)

Sign Rule: You must choose $+$ or $-$ based on the quadrant of $\frac{u}{2}$! For $\tan\left(\frac{u}{2}\right)$, use the rational forms—no $\pm$ needed!

$$\sin\left(\frac{u}{2}\right) = \pm\sqrt{\frac{1 - \cos u}{2}}, \qquad \cos\left(\frac{u}{2}\right) = \pm\sqrt{\frac{1 + \cos u}{2}}$$ $$\tan\left(\frac{u}{2}\right) = \pm\sqrt{\frac{1 - \cos u}{1 + \cos u}} = \frac{1 - \cos u}{\sin u} = \frac{\sin u}{1 + \cos u}$$
4. Power-Reducing Formulas (Larson 5.5)

Angle Doubling: Every time you apply a power-reducing formula, the angle inside $\cos$ doubles ($u \to 2u \to 4u$).

$$\sin^2 u = \frac{1 - \cos(2u)}{2}$$ $$\cos^2 u = \frac{1 + \cos(2u)}{2}$$ $$\tan^2 u = \frac{1 - \cos(2u)}{1 + \cos(2u)}$$
5. Product-to-Sum Formulas (Larson 5.5)

Converts a product of two trig functions into a sum or difference:

$$\sin u \sin v = \frac{1}{2}\big[\cos(u - v) - \cos(u + v)\big]$$ $$\cos u \cos v = \frac{1}{2}\big[\cos(u - v) + \cos(u + v)\big]$$ $$\sin u \cos v = \frac{1}{2}\big[\sin(u + v) + \sin(u - v)\big]$$ $$\cos u \sin v = \frac{1}{2}\big[\sin(u + v) - \sin(u - v)\big]$$
6. Sum-to-Product Formulas (Larson 5.5)

Converts a sum or difference into a product using average $\frac{u+v}{2}$ and half-difference $\frac{u-v}{2}$:

$$\sin u + \sin v = 2\sin\left(\frac{u + v}{2}\right)\cos\left(\frac{u - v}{2}\right)$$ $$\sin u - \sin v = 2\cos\left(\frac{u + v}{2}\right)\sin\left(\frac{u - v}{2}\right)$$ $$\cos u + \cos v = 2\cos\left(\frac{u + v}{2}\right)\cos\left(\frac{u - v}{2}\right)$$ $$\cos u - \cos v = -2\sin\left(\frac{u + v}{2}\right)\sin\left(\frac{u - v}{2}\right)$$
🧮 Pillar 2: Solving Trigonometric Equations (STE Level 1 & Level 2 — Worksheet A)

On Tuesday's quiz, all STE problems are drawn from Level 1 and Level 2 across Categories 1, 2, 3, and 5, solved on $[0, 2\pi)$ without a calculator.

Category 1: Isolating a Trig Function (Lv 1 & 2)

Method: Move all terms with the trig function to one side, constants to the other, convert reciprocals ($\sec x = \frac{1}{\cos x}$, $\csc x = \frac{1}{\sin x}$, $\cot x = \frac{1}{\tan x}$), and identify the two quadrants on $[0, 2\pi)$.

Ex 1 (Wkst A Lv 1 #3): Solve $3\sqrt{3}\tan x = 3$ on $[0, 2\pi)$. $$\tan x = \frac{3}{3\sqrt{3}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$ $$\text{QI & QIII } \left(\theta_{\text{ref}} = \frac{\pi}{6}\right) \implies x = \frac{\pi}{6}, \frac{7\pi}{6}$$
Ex 2 (Wkst A Lv 2 #13): Solve $4\sec x - 2 = 2\sec x$ on $[0, 2\pi)$. $$2\sec x = 2 \implies \sec x = 1 \implies \cos x = 1 \implies x = 0$$
Ex 3 (Wkst A Lv 2 #4): Solve $\sqrt{3}\sec x + 2 = 0$ on $[0, 2\pi)$. $$\sec x = -\frac{2}{\sqrt{3}} \implies \cos x = -\frac{\sqrt{3}}{2} \implies x = \frac{5\pi}{6}, \frac{7\pi}{6}$$
Category 2: By Square Roots (Lv 1 & 2)

Method: Isolate the squared trig function $\text{trig}^2(x) = k$, then take $\pm\sqrt{k}$. Because both positive and negative values are included, you get solutions in all 4 quadrants!

Ex 1 (Wkst A Lv 1 #8): Solve $4\cos^2 x - 3 = 0$ on $[0, 2\pi)$. $$\cos^2 x = \frac{3}{4} \implies \cos x = \pm\frac{\sqrt{3}}{2}$$ $$x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{11\pi}{6}$$
Ex 2 (Wkst A Lv 2 #7): Solve $3\csc^2 x - 4 = 0$ on $[0, 2\pi)$. $$\csc^2 x = \frac{4}{3} \implies \sin^2 x = \frac{3}{4} \implies \sin x = \pm\frac{\sqrt{3}}{2}$$ $$x = \frac{\pi}{3}, \frac{2\pi}{3}, \frac{4\pi}{3}, \frac{5\pi}{3}$$
Ex 3 (Wkst A Lv 2 #11): Solve $\csc^2 x - 2 = 0$ on $[0, 2\pi)$. $$\csc^2 x = 2 \implies \sin x = \pm\frac{\sqrt{2}}{2} \implies x = \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$$
Category 3: By Factoring — GCF & Trinomials (Lv 1 & 2)

Method: Move every term to the left side so the right side is $0$. Factor out a GCF or factor as a quadratic $(a u + b)(c u + d) = 0$. Never divide both sides by a trig function!

Ex 1 (Wkst A Lv 2 #18 — GCF Trap): Solve $3\tan^3 x = \tan x$. $$3\tan^3 x - \tan x = 0 \implies \tan x(3\tan^2 x - 1) = 0$$ $$\tan x = 0 \implies x = 0, \pi$$ $$\tan x = \pm\frac{1}{\sqrt{3}} \implies x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{11\pi}{6}$$ $$\text{All 6 roots: } x = 0, \frac{\pi}{6}, \frac{5\pi}{6}, \pi, \frac{7\pi}{6}, \frac{11\pi}{6}$$
Ex 2 (Wkst A Lv 2 #20 — Quadratic): Solve $\sec^2 x - \sec x = 2$. $$\sec^2 x - \sec x - 2 = 0 \implies (\sec x - 2)(\sec x + 1) = 0$$ $$\sec x = 2 \implies \cos x = \frac{1}{2} \implies x = \frac{\pi}{3}, \frac{5\pi}{3}$$ $$\sec x = -1 \implies \cos x = -1 \implies x = \pi$$
Ex 3 (Wkst A Lv 2 #28): Solve $2\sin^2 x + 5\sin x = 3$. $$2\sin^2 x + 5\sin x - 3 = 0 \implies (2\sin x - 1)(\sin x + 3) = 0$$ $$\sin x = \frac{1}{2} \implies x = \frac{\pi}{6}, \frac{5\pi}{6} \quad (\sin x = -3 \text{ has no solution})$$
Category 5: Multiple-Angle Equations (Lv 2)

Method: When solving $\text{trig}(nx) = c$ on $0 \le x < 2\pi$, first find all solutions for the multiple angle $nx$ on $[0, 2n\pi)$ (go around the circle $n$ times!), and divide by $n$ last.

Ex 1 (Wkst A Lv 2 #42): Solve $\sin(2x) = -\frac{1}{\sqrt{2}}$ on $[0, 2\pi)$. $$\text{Since } 0 \le x < 2\pi \implies 0 \le 2x < 4\pi \text{ (2 revolutions):}$$ $$2x = \frac{5\pi}{4}, \frac{7\pi}{4}, \frac{13\pi}{4}, \frac{15\pi}{4}$$ $$\text{Divide by } 2: \quad x = \frac{5\pi}{8}, \frac{7\pi}{8}, \frac{13\pi}{8}, \frac{15\pi}{8}$$
Ex 2 (Wkst A Lv 2 #37): Solve $\cos(3x) = 0$ on $[0, 2\pi)$. $$\text{Since } 0 \le x < 2\pi \implies 0 \le 3x < 6\pi \text{ (3 revolutions):}$$ $$3x = \frac{\pi}{2}, \frac{3\pi}{2}, \frac{5\pi}{2}, \frac{7\pi}{2}, \frac{9\pi}{2}, \frac{11\pi}{2}$$ $$\text{Divide by } 3: \quad x = \frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{3\pi}{2}, \frac{11\pi}{6}$$
Ex 3 (Wkst A Lv 2 #38): Solve $\sqrt{3}\tan(3x) = 0$ on $[0, 2\pi)$. $$\tan(3x) = 0 \text{ on } [0, 6\pi) \implies 3x = 0, \pi, 2\pi, 3\pi, 4\pi, 5\pi$$ $$\text{Divide by } 3: \quad x = 0, \frac{\pi}{3}, \frac{2\pi}{3}, \pi, \frac{4\pi}{3}, \frac{5\pi}{3}$$

🔹 SRE Section 1: Evaluating Trigonometric Expressions Using Identities (3 Required Problems)

1. Sum/Difference: Pg 384 #19

Problem: Find the exact values of $\sin, \cos,$ and $\tan$ of $\frac{11\pi}{12}$.

Decompose Angle: $$\frac{11\pi}{12} = \frac{8\pi}{12} + \frac{3\pi}{12} = \frac{2\pi}{3} + \frac{\pi}{4}$$ Sine: $$\sin\left(\frac{2\pi}{3} + \frac{\pi}{4}\right) = \sin\frac{2\pi}{3}\cos\frac{\pi}{4} + \cos\frac{2\pi}{3}\sin\frac{\pi}{4}$$ $$= \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{2}}{2}\right) + \left(-\frac{1}{2}\right)\left(\frac{\sqrt{2}}{2}\right) = \frac{\sqrt{6} - \sqrt{2}}{4}$$ Cosine: $$\cos\left(\frac{2\pi}{3} + \frac{\pi}{4}\right) = \cos\frac{2\pi}{3}\cos\frac{\pi}{4} - \sin\frac{2\pi}{3}\sin\frac{\pi}{4}$$ $$= \left(-\frac{1}{2}\right)\left(\frac{\sqrt{2}}{2}\right) - \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{2}}{2}\right) = \frac{-\sqrt{2} - \sqrt{6}}{4}$$ Tangent: $$\tan\left(\frac{2\pi}{3} + \frac{\pi}{4}\right) = \frac{-\sqrt{3} + 1}{1 - (-\sqrt{3})(1)} = \frac{1 - \sqrt{3}}{1 + \sqrt{3}} = \sqrt{3} - 2$$
2. Half-Angle: Pg 395 #45

Problem: Use half-angle formulas to find exact $\sin, \cos, \tan$ of $\frac{7\pi}{8}$.

Setup: $\frac{7\pi}{8} = \frac{7\pi/4}{2}$ so $u = \frac{7\pi}{4}$. Since $\frac{7\pi}{8} \in \text{QII}$, $\sin > 0, \cos < 0, \tan < 0$. $$\cos\left(\frac{7\pi}{4}\right) = \frac{\sqrt{2}}{2}, \qquad \sin\left(\frac{7\pi}{4}\right) = -\frac{\sqrt{2}}{2}$$ Sine ($\text{QII} \implies +$): $$\sin\left(\frac{7\pi}{8}\right) = +\sqrt{\frac{1 - \frac{\sqrt{2}}{2}}{2}} = \sqrt{\frac{2 - \sqrt{2}}{4}} = \frac{\sqrt{2 - \sqrt{2}}}{2}$$ Cosine ($\text{QII} \implies -$): $$\cos\left(\frac{7\pi}{8}\right) = -\sqrt{\frac{1 + \frac{\sqrt{2}}{2}}{2}} = -\frac{\sqrt{2 + \sqrt{2}}}{2}$$ Tangent: $$\tan\left(\frac{7\pi}{8}\right) = \frac{1 - \cos\left(\frac{7\pi}{4}\right)}{\sin\left(\frac{7\pi}{4}\right)} = \frac{1 - \frac{\sqrt{2}}{2}}{-\frac{\sqrt{2}}{2}} = 1 - \sqrt{2}$$
3. Sum-to-Product: Pg 396 #83

Problem: Use a sum-to-product formula to find the exact value of $\sin(75^\circ) + \sin(15^\circ)$.

Formula: $$\sin u + \sin v = 2\sin\left(\frac{u + v}{2}\right)\cos\left(\frac{u - v}{2}\right)$$ Substitute $u = 75^\circ, v = 15^\circ$: $$\sin(75^\circ) + \sin(15^\circ) = 2\sin\left(\frac{75^\circ + 15^\circ}{2}\right)\cos\left(\frac{75^\circ - 15^\circ}{2}\right)$$ $$= 2\sin(45^\circ)\cos(30^\circ)$$ $$= 2\left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) = \frac{\sqrt{6}}{2}$$

🔹 SRE Section 2: Rewriting Trigonometric Expressions Using Identities (6 Required Problems)

4. Sum/Diff Pattern: Pg 384 #29 & Double-Angle: Pg 394 #21
Pg 384 #29: Write as the sine, cosine, or tangent of an angle: $$\cos(3x)\cos(2y) + \sin(3x)\sin(2y) = \cos(3x - 2y)$$ (Recognize $\cos u \cos v + \sin u \sin v = \cos(u - v)$.)
Pg 394 #21: Rewrite using double-angle formulas: $$6\sin x \cos x = 3(2\sin x \cos x) = 3\sin(2x)$$ (And if $4 - 8\sin^2 x = 4(1 - 2\sin^2 x) = 4\cos(2x)$.)
Pg 395 #53 (Half-Angle Rewrite): Simplify radical expression: $$\sqrt{\frac{1 - \cos(6x)}{2}} = \left|\sin\left(\frac{6x}{2}\right)\right| = |\sin(3x)|$$ $$\frac{\sin(4x)}{1 + \cos(4x)} = \tan\left(\frac{4x}{2}\right) = \tan(2x)$$
5. Power-Reducing: Pg 394 #25 & #27 (High-Probability Quiz Problem!)
Pg 394 #25: Rewrite $\cos^4 x$ in terms of the first power of cosine: $$\cos^4 x = (\cos^2 x)^2 = \left(\frac{1 + \cos(2x)}{2}\right)^2 = \frac{1 + 2\cos(2x) + \cos^2(2x)}{4}$$ $$\text{Replace } \cos^2(2x) = \frac{1 + \cos(4x)}{2}:$$ $$= \frac{1}{4}\left(1 + 2\cos(2x) + \frac{1 + \cos(4x)}{2}\right) = \frac{3 + 4\cos(2x) + \cos(4x)}{8}$$
Pg 394 #27: Rewrite $\sin^2 x \cos^2 x$ in terms of the first power of cosine: $$\sin^2 x \cos^2 x = \left(\frac{1 - \cos(2x)}{2}\right)\left(\frac{1 + \cos(2x)}{2}\right) = \frac{1 - \cos^2(2x)}{4}$$ $$= \frac{1}{4}\left(1 - \frac{1 + \cos(4x)}{2}\right) = \frac{1 - \cos(4x)}{8}$$
6. Product-to-Sum: Pg 395 #69
Pg 395 #69: Use product-to-sum formulas to rewrite the product as a sum or difference: $$\sin(5\theta)\sin(3\theta) = \frac{1}{2}\big[\cos(5\theta - 3\theta) - \cos(5\theta + 3\theta)\big]$$ $$= \frac{1}{2}\big[\cos(2\theta) - \cos(8\theta)\big]$$
7. Sum-to-Product: Pg 396 #79
Pg 396 #79: Use sum-to-product formulas to rewrite the sum or difference as a product: $$\sin(5\theta) - \sin(3\theta) = 2\cos\left(\frac{5\theta + 3\theta}{2}\right)\sin\left(\frac{5\theta - 3\theta}{2}\right)$$ $$= 2\cos(4\theta)\sin(\theta)$$

🔹 SRE Section 3: Using Identities & Right Triangles Given Quadrant Conditions (5 Required Problems)

8. Two-Triangle Sum/Diff: Pg 384 #41

Setup: Given $\sin u = \frac{5}{13}$ ($u \in \text{QII}$) and $\cos v = -\frac{3}{5}$ ($v \in \text{QII}$):

Triangle $u$ (QII): $\text{opp}=5, \text{hyp}=13 \implies \text{adj}=-12$ $$\sin u = \frac{5}{13}, \quad \cos u = -\frac{12}{13}, \quad \tan u = -\frac{5}{12}$$ Triangle $v$ (QII): $\text{adj}=-3, \text{hyp}=5 \implies \text{opp}=4$ $$\sin v = \frac{4}{5}, \quad \cos v = -\frac{3}{5}, \quad \tan v = -\frac{4}{3}$$ Evaluate $\sin(u + v)$: $$\sin(u+v) = \left(\frac{5}{13}\right)\left(-\frac{3}{5}\right) + \left(-\frac{12}{13}\right)\left(\frac{4}{5}\right) = -\frac{63}{65}$$ Evaluate $\cos(u - v)$: $$\cos(u-v) = \left(-\frac{12}{13}\right)\left(-\frac{3}{5}\right) + \left(\frac{5}{13}\right)\left(\frac{4}{5}\right) = \frac{56}{65}$$
9. Double-Angle Triangle: Pg 394 #17 & Pg 395 #38h

Setup: Given $\sin u = -\frac{3}{5}$ with $\frac{3\pi}{2} < u < 2\pi$ (Quadrant IV):

Triangle $u$ (QIV): $\text{opp}=-3, \text{hyp}=5 \implies \text{adj}=+4$ $$\sin u = -\frac{3}{5}, \quad \cos u = \frac{4}{5}, \quad \tan u = -\frac{3}{4}$$ Exact Double-Angle Values: $$\sin(2u) = 2\sin u \cos u = 2\left(-\frac{3}{5}\right)\left(\frac{4}{5}\right) = -\frac{24}{25}$$ $$\cos(2u) = \cos^2 u - \sin^2 u = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}$$ $$\tan(2u) = \frac{\sin(2u)}{\cos(2u)} = -\frac{24}{7}$$
10. Half-Angle Triangle: Pg 395 #37a & #49

Setup: Given $\cot u = 3$ with $\pi < u < \frac{3\pi}{2}$ (Quadrant III):

Step 1 — Quadrant of $\frac{u}{2}$: $$\pi < u < \frac{3\pi}{2} \implies \frac{\pi}{2} < \frac{u}{2} < \frac{3\pi}{4} \implies \frac{u}{2} \in \text{QII!}$$ Step 2 — Triangle $u$ (QIII): $\text{adj}=-3, \text{opp}=-1, \text{hyp}=\sqrt{10}$ $$\cos u = -\frac{3}{\sqrt{10}}, \qquad \sin u = -\frac{1}{\sqrt{10}}$$ Step 3 — Half-Angle Values ($\frac{u}{2} \in \text{QII}$): $$\sin\left(\frac{u}{2}\right) = +\sqrt{\frac{1 + \frac{3}{\sqrt{10}}}{2}} = \sqrt{\frac{10 + 3\sqrt{10}}{20}}$$ $$\cos\left(\frac{u}{2}\right) = -\sqrt{\frac{1 - \frac{3}{\sqrt{10}}}{2}} = -\sqrt{\frac{10 - 3\sqrt{10}}{20}}$$ $$\tan\left(\frac{u}{2}\right) = \frac{1 - \cos u}{\sin u} = \frac{1 + \frac{3}{\sqrt{10}}}{-\frac{1}{\sqrt{10}}} = -3 - \sqrt{10}$$

🔹 SRE Section 4: Rewriting Inverse Trig Composites as Algebraic Expressions in $x$ (3 Required Problems)

11. Single Inverse Sum/Diff: Pg 385 #45

Problem: Write $\sin\left(\frac{\pi}{3} - \arccos x\right)$ as an algebraic expression in $x$.

Let $v = \arccos x$: $$\cos v = \frac{x}{1} \implies \text{adj}=x, \text{hyp}=1 \implies \text{opp}=\sqrt{1 - x^2}$$ $$\sin v = \sqrt{1 - x^2}$$ Apply $\sin(u - v)$: $$\sin\left(\frac{\pi}{3}\right)\cos v - \cos\left(\frac{\pi}{3}\right)\sin v$$ $$= \left(\frac{\sqrt{3}}{2}\right)(x) - \left(\frac{1}{2}\right)\sqrt{1 - x^2} = \frac{\sqrt{3}x - \sqrt{1 - x^2}}{2}$$
12. Two-Inverse Sum/Diff: Pg 385 #61

Problem: Write $\sin(\arctan x + \arccos x)$ as an algebraic expression in $x$.

Triangle $u = \arctan x$: $\text{opp}=x, \text{adj}=1, \text{hyp}=\sqrt{1 + x^2}$ $$\sin u = \frac{x}{\sqrt{1 + x^2}}, \qquad \cos u = \frac{1}{\sqrt{1 + x^2}}$$ Triangle $v = \arccos x$: $\text{adj}=x, \text{hyp}=1, \text{opp}=\sqrt{1 - x^2}$ $$\sin v = \sqrt{1 - x^2}, \qquad \cos v = x$$ Expand $\sin(u + v) = \sin u \cos v + \cos u \sin v$: $$= \left(\frac{x}{\sqrt{1 + x^2}}\right)(x) + \left(\frac{1}{\sqrt{1 + x^2}}\right)\sqrt{1 - x^2}$$ $$= \frac{x^2 + \sqrt{1 - x^2}}{\sqrt{1 + x^2}}$$
13. Double-Angle Inverse: Pg 396 #115

Problem: Write $\sin(2\arcsin x)$ and $\cos(2\arcsin x)$ as algebraic expressions in $x$.

Let $u = \arcsin x$: $\text{opp}=x, \text{hyp}=1 \implies \text{adj}=\sqrt{1 - x^2}$ $$\sin u = x, \qquad \cos u = \sqrt{1 - x^2}$$ For $\sin(2\arcsin x)$: $$\sin(2u) = 2\sin u \cos u = 2x\sqrt{1 - x^2}$$ For $\cos(2\arcsin x)$: $$\cos(2u) = 1 - 2\sin^2 u = 1 - 2x^2$$
⚠️ Pillar 4: Top 6 Unit 4 Quiz Traps & Error Prevention
Read Before Walking Into Class Tuesday
Trap 1: Dividing Both Sides by a Trig Function (STE Cat 3)

In $3\tan^3 x = \tan x$ or $\sec x \csc x = 2\csc x$, NEVER divide by $\tan x$ or $\csc x$! Dividing erases every root where that function equals zero. Always subtract to make one side $0$ and factor out the GCF.

Trap 2: Forgetting $\pm$ When Taking Square Roots (STE Cat 2)

In $4\cos^2 x - 3 = 0 \implies \cos^2 x = \frac{3}{4}$, taking the square root gives $\cos x = \pm\frac{\sqrt{3}}{2}$. Forgetting the $-$ sign costs you half the solutions (Quadrants II and III)!

Trap 3: Dividing by $n$ Too Early in Multiple-Angle Equations (STE Cat 5)

In $\sin(2x) = -\frac{\sqrt{2}}{2}$ on $[0, 2\pi)$, do NOT divide $\frac{5\pi}{4}$ and $\frac{7\pi}{4}$ by $2$ and stop! Because $2x \in [0, 4\pi)$, you must add $2\pi$ to get $\frac{13\pi}{4}$ and $\frac{15\pi}{4}$ before dividing by $2$.

Trap 4: Using the Quadrant of $u$ Instead of $\frac{u}{2}$ (SRE Sec 3)

If $u$ is in Quadrant III ($\pi < u < \frac{3\pi}{2}$), $\cos u$ is negative—but $\frac{u}{2}$ satisfies $\frac{\pi}{2} < \frac{u}{2} < \frac{3\pi}{4}$ (Quadrant II!), so $\sin\left(\frac{u}{2}\right)$ is positive and $\cos\left(\frac{u}{2}\right)$ is negative.

Trap 5: Stopping Halfway on Power-Reducing (SRE Sec 2)

When rewriting $\cos^4 x$ or $\sin^2 x \cos^2 x$ to the first power of cosine, a $\cos^2(2x)$ term appears after the first step. You must apply Power-Reducing a second time: $\cos^2(2x) = \frac{1 + \cos(4x)}{2}$.

Trap 6: Boxing or Circling Answers on Worksheet B

Mr. O'Connor's Rule #6 explicitly states: DO NOT box or circle your final answers on Worksheets A, B, or C. Leave the final line clean!

Q1 • STE Level 1 (Isolate) Solve $2\sin x + \sqrt{3} = 0$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
$$2\sin x = -\sqrt{3} \implies \sin x = -\frac{\sqrt{3}}{2}$$ Sine is negative in Quadrants III and IV with reference angle $\frac{\pi}{3}$: $$x = \frac{4\pi}{3}, \frac{5\pi}{3}$$
Q2 • STE Level 2 (Isolate Reciprocal) Solve $\sqrt{3}\csc x - 2 = 0$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
$$\csc x = \frac{2}{\sqrt{3}} \implies \sin x = \frac{\sqrt{3}}{2}$$ Sine is positive in Quadrants I and II with reference angle $\frac{\pi}{3}$: $$x = \frac{\pi}{3}, \frac{2\pi}{3}$$
Q3 • STE Level 2 (Square Roots) Solve $3\cot^2 x - 1 = 0$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
$$\cot^2 x = \frac{1}{3} \implies \tan^2 x = 3 \implies \tan x = \pm\sqrt{3}$$ Reference angle is $\frac{\pi}{3}$ in all 4 quadrants: $$x = \frac{\pi}{3}, \frac{2\pi}{3}, \frac{4\pi}{3}, \frac{5\pi}{3}$$
Q4 • STE Level 2 (Factoring GCF Trap) Solve $2\sin^2 x = \sin x$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
Subtract $\sin x$ (do NOT divide by $\sin x$): $$2\sin^2 x - \sin x = 0 \implies \sin x(2\sin x - 1) = 0$$
  • $\sin x = 0 \implies x = 0, \pi$
  • $2\sin x - 1 = 0 \implies \sin x = \frac{1}{2} \implies x = \frac{\pi}{6}, \frac{5\pi}{6}$
$$x = 0, \frac{\pi}{6}, \frac{5\pi}{6}, \pi$$
Q5 • STE Level 2 (Factoring Quadratic) Solve $2\cos^2 x + \cos x - 1 = 0$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
$$(2\cos x - 1)(\cos x + 1) = 0$$
  • $\cos x = \frac{1}{2} \implies x = \frac{\pi}{3}, \frac{5\pi}{3}$
  • $\cos x = -1 \implies x = \pi$
$$x = \frac{\pi}{3}, \pi, \frac{5\pi}{3}$$
Q6 • STE Level 2 (Multiple Angles) Solve $\cos(2x) = -\frac{1}{2}$ on $[0, 2\pi)$.
Reveal Step-by-Step Solution
Let $u = 2x \in [0, 4\pi)$. Cosine equals $-\frac{1}{2}$ in Quadrants II and III ($\frac{2\pi}{3}, \frac{4\pi}{3}$): $$2x = \frac{2\pi}{3}, \frac{4\pi}{3}, \frac{8\pi}{3}, \frac{10\pi}{3}$$ Divide all solutions by $2$: $$x = \frac{\pi}{3}, \frac{2\pi}{3}, \frac{4\pi}{3}, \frac{5\pi}{3}$$
Q7 • SRE Section 1 (Exact Sum/Diff Evaluation) Find the exact value of $\cos\left(\frac{7\pi}{12}\right)$.
Reveal Step-by-Step Solution
Split $\frac{7\pi}{12} = \frac{3\pi}{12} + \frac{4\pi}{12} = \frac{\pi}{4} + \frac{\pi}{3}$: $$\cos\left(\frac{\pi}{4} + \frac{\pi}{3}\right) = \cos\frac{\pi}{4}\cos\frac{\pi}{3} - \sin\frac{\pi}{4}\sin\frac{\pi}{3}$$ $$= \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) - \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) = \frac{\sqrt{2} - \sqrt{6}}{4}$$
Q8 • SRE Section 1 (Exact Half-Angle Evaluation) Find the exact value of $\tan\left(\frac{5\pi}{8}\right)$.
Reveal Step-by-Step Solution
Since $\frac{5\pi}{8} = \frac{5\pi/4}{2}$, let $u = \frac{5\pi}{4}$ (Quadrant III: $\sin u = -\frac{\sqrt{2}}{2}, \cos u = -\frac{\sqrt{2}}{2}$). Using the rational half-angle formula: $$\tan\left(\frac{5\pi}{8}\right) = \frac{1 - \cos\left(\frac{5\pi}{4}\right)}{\sin\left(\frac{5\pi}{4}\right)} = \frac{1 - \left(-\frac{\sqrt{2}}{2}\right)}{-\frac{\sqrt{2}}{2}} = \frac{2 + \sqrt{2}}{-\sqrt{2}} = -\sqrt{2} - 1$$
Q9 • SRE Section 2 (Power-Reducing) Rewrite $\sin^4 x$ in terms of the first power of cosine.
Reveal Step-by-Step Solution
$$\sin^4 x = (\sin^2 x)^2 = \left(\frac{1 - \cos(2x)}{2}\right)^2 = \frac{1 - 2\cos(2x) + \cos^2(2x)}{4}$$ Substitute $\cos^2(2x) = \frac{1 + \cos(4x)}{2}$: $$= \frac{1}{4}\left(1 - 2\cos(2x) + \frac{1 + \cos(4x)}{2}\right) = \frac{3 - 4\cos(2x) + \cos(4x)}{8}$$
Q10 • SRE Section 3 (2-Triangle Sum/Diff) Given $\sin u = -\frac{4}{5}$ ($u \in \text{QIII}$) and $\cos v = -\frac{12}{13}$ ($v \in \text{QII}$), find the exact value of $\cos(u + v)$.
Reveal Step-by-Step Solution
  • For $u \in \text{QIII}$: $\sin u = -\frac{4}{5} \implies \cos u = -\frac{3}{5}$.
  • For $v \in \text{QII}$: $\cos v = -\frac{12}{13} \implies \sin v = +\frac{5}{13}$.
$$\cos(u + v) = \cos u \cos v - \sin u \sin v = \left(-\frac{3}{5}\right)\left(-\frac{12}{13}\right) - \left(-\frac{4}{5}\right)\left(\frac{5}{13}\right) = \frac{36 + 20}{65} = \frac{56}{65}$$
Q11 • SRE Section 3 (Half-Angle from Triangle) Given $\cos u = -\frac{4}{5}$ with $\pi < u < \frac{3\pi}{2}$, find the exact value of $\cos\left(\frac{u}{2}\right)$.
Reveal Step-by-Step Solution
First find the quadrant of $\frac{u}{2}$: $$\pi < u < \frac{3\pi}{2} \implies \frac{\pi}{2} < \frac{u}{2} < \frac{3\pi}{4} \implies \frac{u}{2} \in \text{Quadrant II } (\cos(u/2) < 0)$$ $$\cos\left(\frac{u}{2}\right) = -\sqrt{\frac{1 + \cos u}{2}} = -\sqrt{\frac{1 - \frac{4}{5}}{2}} = -\sqrt{\frac{1}{10}} = -\frac{\sqrt{10}}{10}$$
Q12 • SRE Section 4 (Algebraic Inverse Composite) Rewrite $\cos(\arcsin x + \arctan x)$ as an algebraic expression in $x$.
Reveal Step-by-Step Solution
  • Let $u = \arcsin x \implies \sin u = x, \cos u = \sqrt{1 - x^2}$.
  • Let $v = \arctan x \implies \sin v = \frac{x}{\sqrt{1 + x^2}}, \cos v = \frac{1}{\sqrt{1 + x^2}}$.
$$\cos(u + v) = \cos u \cos v - \sin u \sin v = \left(\sqrt{1 - x^2}\right)\left(\frac{1}{\sqrt{1 + x^2}}\right) - (x)\left(\frac{x}{\sqrt{1 + x^2}}\right) = \frac{\sqrt{1 - x^2} - x^2}{\sqrt{1 + x^2}}$$
