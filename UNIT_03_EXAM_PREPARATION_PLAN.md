## 🎯 Step-by-Step Study Order: What to Study in What Sequence

To prevent cognitive overload, do not study topics out of order. Follow this exact 5-phase progression:

### Phase 1: No-Calculator Core Foundations (Lessons 1, 2, 3)
1. **Principal Branches:** Memorize the exact ranges:
   * $\arcsin x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ (QI & QIV, where QIV is written as negative angles $[-\pi/2, 0)$).
   * $\arccos x \in [0, \pi]$ (QI & QII).
   * $\arctan x \in (-\frac{\pi}{2}, \frac{\pi}{2})$ (QI & QIV open interval).
2. **Numeric Compositions:**
   * If input is inside principal branch: $\sin(\arcsin(1/2)) = 1/2$.
   * If input is OUTSIDE: $\arcsin(\sin(5\pi/6)) = \pi/6$ (because $5\pi/6$ is in QII, where sine is positive, so the principal output in QI is $\pi/6$).
3. **Algebraic Compositions (Reference Right Triangles):**
   * Set $\theta = \arccos(x) \implies \cos\theta = \frac{x}{1} = \frac{\text{adj}}{\text{hyp}}$.
   * Calculate opposite side using Pythagorean theorem: $\text{opp} = \sqrt{1 - x^2}$.
   * Evaluate desired outer function: $\tan(\arccos(x)) = \frac{\text{opp}}{\text{adj}} = \frac{\sqrt{1-x^2}}{x}$.
4. **Worksheets to Practice:** [Wkst A](./docs/APPCU03_WkstA_EvalInvFxns.pdf) and [Wkst B (Arc Trig)](./docs/APPCU03_WkstB_EvalArcTrig.pdf).

### Phase 2: Identities & Area Formulas (Lesson 4)
1. **Pythagorean Identities:**
   $$\sin^2\theta + \cos^2\theta = 1 \quad|\quad 1 + \tan^2\theta = \sec^2\theta \quad|\quad 1 + \cot^2\theta = \csc^2\theta$$
2. **Area of Oblique Triangles:**
   * **$SAS$ Formula (Two sides & included angle):** $\text{Area} = \frac{1}{2}ab\sin C$
   * **$SSS$ Formula (Heron's):**
     * Step 1: $s = \frac{a + b + c}{2}$ (semi-perimeter).
     * Step 2: $\text{Area} = \sqrt{s(s-a)(s-b)(s-c)}$.

### Phase 3: Calculator Oblique Triangles & SSA Ambiguous Case (Lessons 5, 6, 7)
1. **Law of Cosines ($SAS$ and $SSS$):**
   $$c^2 = a^2 + b^2 - 2ab\cos C \iff \cos C = \frac{a^2 + b^2 - c^2}{2ab}$$
   * **Golden Rule for $SSS$:** Always solve for the **largest side's opposite angle first**! If that angle is obtuse, $\cos$ will be negative. Once the largest angle is found, both remaining angles MUST be acute, preventing any ambiguity when using the Law of Sines for the remaining angles!
2. **Law of Sines ($AAS$ and $ASA$):**
   $$\frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c}$$
3. **Ambiguous Case ($SSA$):**
   * Given acute angle $A$ and adjacent side $b$, find altitude: **$h = b\sin A$**.
   * Compare opposite side $a$ with $h$ and $b$:
     * If $a < h \implies$ **0 Triangles (No solution)**.
     * If $a = h \implies$ **1 Right Triangle**.
     * If $h < a < b \implies$ **2 Oblique Triangles**.
       * Angle $B_1 = \arcsin\left(\frac{b\sin A}{a}\right)$ (acute).
       * Angle $B_2 = 180^\circ - B_1$ (obtuse). Check: $A + B_2 < 180^\circ$.
       * Solve both triangles completely!
     * If $a \ge b \implies$ **1 Oblique Triangle**.
4. **Worksheets to Practice:** [Wkst B (Oblique)](./docs/APPCU03_WkstB_AppsObliqueTriangles.pdf) and [Wkst C (SSA)](./docs/APPCU03_WkstC_ExtraPracSSA.pdf).
