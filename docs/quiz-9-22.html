🏛️ Pillar 1: General Inverses & Function Tables (Lesson 1)

Worksheet A Focus

Inverses swap domain and range: $(x, y) \to (y, x)$. A function has an inverse function if and only if it passes the Horizontal Line Test (one-to-one).

Key Composition Property: $$(f \circ g)^{-1}(x) = (g^{-1} \circ f^{-1})(x) = g^{-1}(f^{-1}(x))$$ Notice the order flips! Always evaluate the inner function first.
Evaluating Polynomial Inverses $f^{-1}(c)$:
  1. Set $f(x) = c$.
  2. Subtract $c$ to get $f(x) - c = 0$.
  3. Factor by grouping or synthetic division. (Remember: because polynomials can have multiple pre-images, $f^{-1}(c)$ can yield multiple values!)
Example: If $f(x) = x^3 - 7x^2 - 8x + 5$, evaluate $f^{-1}(5)$.
$x^3 - 7x^2 - 8x + 5 = 5 \implies x(x^2 - 7x - 8) = 0 \implies x(x - 8)(x + 1) = 0 \implies \mathbf{x = 0, 8, -1}$.

🏛️ Pillar 2: Arc Trig Strict Range Restrictions (Lesson 2)

Worksheet B Focus

Because trig functions are periodic, their domains were strictly restricted to define inverses. You MUST memorize these output boundaries:

Function Input Domain Strict Output Range ($\theta$) Active Quadrants Critical Pitfall Alert
$\theta = \arcsin(x)$ $[-1, 1]$ $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ Quadrants I & IV Negative angles MUST be written as negative acute (e.g. $-\frac{\pi}{6}$), NEVER $11\pi/6$!
$\theta = \arccos(x)$ $[-1, 1]$ $[0, \pi]$ Quadrants I & II Negative inputs produce obtuse angles in Quadrant II (e.g. $\frac{2\pi}{3}, \frac{3\pi}{4}, \frac{5\pi}{6}$).
$\theta = \arctan(x)$ $(-\infty, \infty)$ $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ Quadrants I & IV Open interval due to vertical asymptotes at $\pm\pi/2$.
$\theta = \text{arcsec}(x)$ $(-\infty, -1] \cup [1, \infty)$ $[0, \pi], \theta \neq \frac{\pi}{2}$ Quadrants I & II Equal to $\arccos(1/x)$. $\text{arcsec}(-2) = \arccos(-1/2) = \mathbf{\frac{2\pi}{3}}$.
$\theta = \text{arccsc}(x)$ $(-\infty, -1] \cup [1, \infty)$ $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right], \theta \neq 0$ Quadrants I & IV Equal to $\arcsin(1/x)$. $\text{arccsc}(\sqrt{2}) = \arcsin(\sqrt{2}/2) = \mathbf{\frac{\pi}{4}}$.
🚨 The #1 Mistake on Unit 3 Quizzes:
Evaluating $\arcsin(-1/2)$ as $11\pi/6$ or $7\pi/6$. In AP Precalculus, the range is strictly $[-\pi/2, \pi/2]$, so you will get 0 credit for $11\pi/6$. The ONLY correct answer is $-\frac{\pi}{6}$!

🏛️ Pillar 3: Composite Trig & Right Triangle Modeling (Lesson 3)

Videos 4, 5, 6
Rule A — Out-of-Bounds Cancellation:
$\arcsin(\sin\theta) = \theta$ ONLY IF $\theta \in [-\pi/2, \pi/2]$.
If $\theta$ is outside this range, evaluate in 2 steps:
$$\arcsin\left(\sin\left(\frac{5\pi}{6}\right)\right) \implies \sin\left(\frac{5\pi}{6}\right) = \frac{1}{2} \implies \arcsin\left(\frac{1}{2}\right) = \mathbf{\frac{\pi}{6}}$$ $$\arccos\left(\cos\left(\frac{7\pi}{4}\right)\right) \implies \cos\left(\frac{7\pi}{4}\right) = \frac{\sqrt{2}}{2} \implies \arccos\left(\frac{\sqrt{2}}{2}\right) = \mathbf{\frac{\pi}{4}}$$
Rule B — 4-Step Right Triangle Method for Variable Algebraic Composites:
  1. Let $\theta = \text{inner arc function}$. For example, $\theta = \arccos(2x)$.
  2. Write ratio: $\cos\theta = \frac{2x}{1} = \frac{\text{Adjacent}}{\text{Hypotenuse}}$.
  3. Draw right triangle and use $a^2 + b^2 = c^2$: $\text{Opposite} = \sqrt{1^2 - (2x)^2} = \sqrt{1 - 4x^2}$.
  4. Evaluate outer function: $\tan(\arccos(2x)) = \frac{\text{Opposite}}{\text{Adjacent}} = \mathbf{\frac{\sqrt{1 - 4x^2}}{2x}}$.

🧠 Trig Identities Memorization Bank (TD 23–25)

Daily Drill Formulas

Required for daily class drills starting Monday (9/21). Write these out until you can recall all of them instantly:

Double-Angle Formulas

sin(2θ) = 2 sin θ cos θ cos(2θ) = cos²θ - sin²θ cos(2θ) = 2cos²θ - 1 cos(2θ) = 1 - 2sin²θ tan(2θ) = 2tan θ / (1 - tan²θ)

Sum & Difference Formulas

sin(u ± v) = sin u cos v ± cos u sin v cos(u ± v) = cos u cos v ∓ sin u sin v tan(u ± v) = (tan u ± tan v) / (1 ∓ tan u tan v)

Half-Angle Formulas

sin(u/2) = ±√[(1 - cos u) / 2] cos(u/2) = ±√[(1 + cos u) / 2] tan(u/2) = (1 - cos u) / sin u tan(u/2) = sin u / (1 + cos u)

Power-Reducing Formulas

sin²u = [1 - cos(2u)] / 2 cos²u = [1 + cos(2u)] / 2 tan²u = [1 - cos(2u)] / [1 + cos(2u)]

Q1: If $g(x) = x^3 + 3x^2 - 4x - 10$, evaluate $g^{-1}(2)$. ▼ Show Solution
Set $g(x) = 2$:
$$x^3 + 3x^2 - 4x - 10 = 2 \implies x^3 + 3x^2 - 4x - 12 = 0$$ Factor by grouping:
$$x^2(x + 3) - 4(x + 3) = 0 \implies (x^2 - 4)(x + 3) = 0 \implies (x - 2)(x + 2)(x + 3) = 0$$ Answer: $\mathbf{g^{-1}(2) = -3, -2, 2}$
Q2: Given $(f \circ g)^{-1}(x) = (g^{-1} \circ f^{-1})(x)$. If $f(2) = 3$ and $g(3) = 2$, find $(f \circ g)^{-1}(3)$. ▼ Show Solution
Using property $(f \circ g)^{-1}(3) = g^{-1}(f^{-1}(3))$.
Since $f(2) = 3$, $f^{-1}(3) = 2$.
Now find $g^{-1}(2)$: since $g(3) = 2$, $g^{-1}(2) = 3$.
Answer: $\mathbf{3}$
Q3: Evaluate $\arcsin\left(-\frac{\sqrt{3}}{2}\right)$ in exact radians. ▼ Show Solution
$\arcsin$ range is $[-\pi/2, \pi/2]$ (Quadrants I & IV).
Negative values go into Quadrant IV as a negative acute angle.
Reference angle is $\pi/3$, so in QIV: $\mathbf{-\frac{\pi}{3}}$.
(Caution: $5\pi/3$ will receive 0 credit!)
Q4: Evaluate $\arccos\left(-\frac{\sqrt{2}}{2}\right)$ in exact radians. ▼ Show Solution
$\arccos$ range is $[0, \pi]$ (Quadrants I & II).
Negative values go into Quadrant II.
Reference angle is $\pi/4 \implies \theta = \pi - \frac{\pi}{4} = \mathbf{\frac{3\pi}{4}}$.
Q5: Evaluate $\text{arcsec}(-2)$ in exact radians. ▼ Show Solution
$\text{arcsec}(-2) = \arccos\left(-\frac{1}{2}\right)$ in Quadrant II.
Reference angle is $\pi/3 \implies \theta = \pi - \frac{\pi}{3} = \mathbf{\frac{2\pi}{3}}$.
Q6: Evaluate $\arcsin\left(\sin\left(\frac{5\pi}{6}\right)\right)$. ▼ Show Solution
Notice $\frac{5\pi}{6} \notin [-\pi/2, \pi/2]$, so they DO NOT just cancel!
Step 1: Evaluate inner function: $\sin\left(\frac{5\pi}{6}\right) = \frac{1}{2}$.
Step 2: Evaluate outer function: $\arcsin\left(\frac{1}{2}\right) = \mathbf{\frac{\pi}{6}}$.
Q7: Evaluate $\arccos\left(\cos\left(-\frac{\pi}{3}\right)\right)$. ▼ Show Solution
Step 1: $\cos(-\pi/3) = \cos(\pi/3) = \frac{1}{2}$.
Step 2: $\arccos(1/2) = \mathbf{\frac{\pi}{3}}$.
Q8: Evaluate $\tan\left(\arccos\left(-\frac{5}{13}\right)\right)$. ▼ Show Solution
Let $\theta = \arccos(-5/13) \implies \theta \in \text{Quadrant II}$.
In QII: $\text{Adjacent} = -5$, $\text{Hypotenuse} = 13$.
$\text{Opposite} = \sqrt{13^2 - (-5)^2} = \sqrt{144} = 12$ (positive in QII).
$\tan\theta = \frac{\text{Opposite}}{\text{Adjacent}} = \frac{12}{-5} = \mathbf{-\frac{12}{5}}$.
Q9: Write $\sin(\arccos(2x))$ as an algebraic expression in $x$. ▼ Show Solution
Let $\theta = \arccos(2x/1) \implies \cos\theta = \frac{2x}{1}$.
$\text{Adjacent} = 2x$, $\text{Hypotenuse} = 1$.
$\text{Opposite} = \sqrt{1^2 - (2x)^2} = \sqrt{1 - 4x^2}$.
$\sin\theta = \frac{\text{Opposite}}{\text{Hypotenuse}} = \mathbf{\sqrt{1 - 4x^2}}$.
Q10: Write $\tan\left(\arcsin\left(\frac{x}{\sqrt{x^2 + 25}}\right)\right)$ as an algebraic expression in $x$. ▼ Show Solution
Let $\theta = \arcsin\left(\frac{x}{\sqrt{x^2+25}}\right) \implies \text{Opposite} = x, \text{Hypotenuse} = \sqrt{x^2+25}$.
$\text{Adjacent} = \sqrt{(\sqrt{x^2+25})^2 - x^2} = \sqrt{x^2 + 25 - x^2} = \sqrt{25} = 5$.
$\tan\theta = \frac{\text{Opposite}}{\text{Adjacent}} = \mathbf{\frac{x}{5}}$.
