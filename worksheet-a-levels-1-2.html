Category 1: Isolate

Get the trig function alone, then use the unit circle.

Level 1

#1Level 1 (1 pt)
Solve on $[0, 2\pi]$:   $\displaystyle 2\cos x - 1 = 0$
Formula / idea used: Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).
Show steps and answer
$\displaystyle 2\cos x = 1 \implies \cos x = \frac{1}{2}$

Cosine is positive in QI and QIV; reference angle $\frac{\pi}{3}$.

$\displaystyle x = \frac{\pi}{3},\ \frac{5\pi}{3}$

Show steps and answer

Solve on $[0, 2\pi]$:   $\displaystyle \sqrt{3}\sec x + 2 = 0$
Formula / idea used: Reciprocal identity: $\sec x = \frac{1}{\cos x}$. Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).

#8Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \cot x - \sqrt{3} = 0$
Formula / idea used: Reciprocal identity: $\cot x = \frac{1}{\tan x}$. Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).
Show steps and answer
$\displaystyle \cot x = \sqrt{3} \implies \tan x = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$

Tangent (and cotangent) is positive in QI and QIII; reference angle $\frac{\pi}{6}$.

$\displaystyle x = \frac{\pi}{6},\ \frac{7\pi}{6}$
#9Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \sin x - \sqrt{3} = -\sin x$
Formula / idea used: Collect like terms, then Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).
Show steps and answer
$\displaystyle \sin x + \sin x = \sqrt{3} \implies 2\sin x = \sqrt{3} \implies \sin x = \frac{\sqrt{3}}{2}$

Sine is positive in QI and QII; reference angle $\frac{\pi}{3}$.

$\displaystyle x = \frac{\pi}{3},\ \frac{2\pi}{3}$
#10Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle 4\sec x - 2 = 2\sec x$
Formula / idea used: Reciprocal identity: $\sec x = \frac{1}{\cos x}$. On the closed interval $[0, 2\pi]$, include both endpoints when they work.
Show steps and answer
$\displaystyle 4\sec x - 2\sec x = 2 \implies 2\sec x = 2 \implies \sec x = 1$
$\displaystyle \cos x = 1$

Cosine equals $1$ only on the positive $x$-axis: $x = 0$ and $x = 2\pi$.

$\displaystyle x = 0,\ 2\pi$
#11Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \tfrac{1}{2}\sec x - 1 = 0$
Formula / idea used: Reciprocal identity: $\sec x = \frac{1}{\cos x}$. Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).
Show steps and answer
$\displaystyle \tfrac{1}{2}\sec x = 1 \implies \sec x = 2 \implies \cos x = \frac{1}{2}$

Cosine is positive in QI and QIV; reference angle $\frac{\pi}{3}$.

$\displaystyle x = \frac{\pi}{3},\ \frac{5\pi}{3}$

Category 2: By Square Roots

Isolate the squared function, take $\pm\sqrt{\ }$, and find the angles in all quadrants that fit.

Level 1

#22Level 1 (1 pt)
Solve on $[0, 2\pi]$:   $\displaystyle 4\cos^2 x - 1 = 0$
Formula / idea used: Square-root property: if $u^2 = k$, then $u = \pm\sqrt{k}$. The $\pm$ gives angles in all four quadrants.
Show steps and answer
$\displaystyle 4\cos^2 x = 1 \implies \cos^2 x = \frac{1}{4} \implies \cos x = \pm\frac{1}{2}$

Reference angle $\frac{\pi}{3}$ in every quadrant.

$\displaystyle x = \frac{\pi}{3},\ \frac{2\pi}{3},\ \frac{4\pi}{3},\ \frac{5\pi}{3}$

Show steps and answer

#27Level 2 (3 pts)

Category 3: By Factoring

Move everything to one side, factor, and set each factor to $0$. Never divide by a trig function.

Level 1

#34Level 1 (1 pt)
Solve on $[0, 2\pi]$:   $\displaystyle \cos x(\cos x - 1) = 0$
Formula / idea used: Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$. On $[0, 2\pi]$, include $2\pi$ whenever $0$ works.
Show steps and answer
$\displaystyle \cos x = 0 \quad\text{or}\quad \cos x - 1 = 0$
$\displaystyle \cos x = 0 \implies x = \frac{\pi}{2},\ \frac{3\pi}{2}$
$\displaystyle \cos x = 1 \implies x = 0,\ 2\pi$
$\displaystyle x = 0,\ \frac{\pi}{2},\ \frac{3\pi}{2},\ 2\pi$
#35Level 1 (1 pt)
Solve on $[0, 2\pi]$:   $\displaystyle (\sqrt{3}\tan x - 1)(\tan x - \sqrt{3}) = 0$
Formula / idea used: Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$. Unit circle: reference angles $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ and the quadrant signs (All Students Take Calculus).
Show steps and answer
$\displaystyle \sqrt{3}\tan x - 1 = 0 \implies \tan x = \frac{1}{\sqrt{3}} \implies x = \frac{\pi}{6},\ \frac{7\pi}{6}$
$\displaystyle \tan x - \sqrt{3} = 0 \implies \tan x = \sqrt{3} \implies x = \frac{\pi}{3},\ \frac{4\pi}{3}$
$\displaystyle x = \frac{\pi}{6},\ \frac{\pi}{3},\ \frac{7\pi}{6},\ \frac{4\pi}{3}$
#36Level 1 (1 pt)
Solve on $[0, 2\pi]$:   $\displaystyle \sin x(6\sin x + 3) = 0$
Formula / idea used: Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$. On $[0, 2\pi]$, include $2\pi$ whenever $0$ works.
Show steps and answer
$\displaystyle \sin x = 0 \implies x = 0,\ \pi,\ 2\pi$
$\displaystyle 6\sin x + 3 = 0 \implies \sin x = -\frac{1}{2} \implies x = \frac{7\pi}{6},\ \frac{11\pi}{6}$
$\displaystyle x = 0,\ \pi,\ \frac{7\pi}{6},\ \frac{11\pi}{6},\ 2\pi$

Level 2

#37Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle 3\tan^3 x = \tan x$
Formula / idea used: Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$. Do not divide by $\tan x$: that loses the solutions where $\tan x = 0$.
Show steps and answer
$\displaystyle 3\tan^3 x - \tan x = 0 \implies \tan x\,(3\tan^2 x - 1) = 0$
$\displaystyle \tan x = 0 \implies x = 0,\ \pi,\ 2\pi$
$\displaystyle 3\tan^2 x = 1 \implies \tan x = \pm\frac{1}{\sqrt{3}} \implies x = \frac{\pi}{6},\ \frac{5\pi}{6},\ \frac{7\pi}{6},\ \frac{11\pi}{6}$
$\displaystyle x = 0,\ \frac{\pi}{6},\ \frac{5\pi}{6},\ \pi,\ \frac{7\pi}{6},\ \frac{11\pi}{6},\ 2\pi$
#38Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \sec^2 x - \sec x = 2$
Formula / idea used: Quadratic in $\sec x$: factor like $u^2 - u - 2 = (u - 2)(u + 1)$. Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$.
Show steps and answer
$\displaystyle \sec^2 x - \sec x - 2 = 0 \implies (\sec x - 2)(\sec x + 1) = 0$
$\displaystyle \sec x = 2 \implies \cos x = \frac{1}{2} \implies x = \frac{\pi}{3},\ \frac{5\pi}{3}$
$\displaystyle \sec x = -1 \implies \cos x = -1 \implies x = \pi$
$\displaystyle x = \frac{\pi}{3},\ \pi,\ \frac{5\pi}{3}$
#38bLevel 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \sec x\csc x = 2\csc x$
Formula / idea used: Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$. Do not divide by $\csc x$; factor it out instead.
Show steps and answer
$\displaystyle \sec x\csc x - 2\csc x = 0 \implies \csc x\,(\sec x - 2) = 0$

$\csc x = 0$ has no solution, because $|\csc x| \ge 1$.

$\displaystyle \sec x = 2 \implies \cos x = \frac{1}{2} \implies x = \frac{\pi}{3},\ \frac{5\pi}{3}$

Check: $\csc x$ is defined at both answers (it is undefined only at $0, \pi, 2\pi$).

$\displaystyle x = \frac{\pi}{3},\ \frac{5\pi}{3}$
#39Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle 2\cos^2 x + \cos x - 1 = 0$
Formula / idea used: Quadratic in $\cos x$: factor like $2u^2 + u - 1 = (2u - 1)(u + 1)$. Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$.
Show steps and answer
$\displaystyle (2\cos x - 1)(\cos x + 1) = 0$
$\displaystyle \cos x = \frac{1}{2} \implies x = \frac{\pi}{3},\ \frac{5\pi}{3}$
$\displaystyle \cos x = -1 \implies x = \pi$
$\displaystyle x = \frac{\pi}{3},\ \pi,\ \frac{5\pi}{3}$
#40Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle 2\sin^2 x + 3\sin x + 1 = 0$
Formula / idea used: Quadratic in $\sin x$: factor like $2u^2 + 3u + 1 = (2u + 1)(u + 1)$. Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$.
Show steps and answer
$\displaystyle (2\sin x + 1)(\sin x + 1) = 0$
$\displaystyle \sin x = -\frac{1}{2} \implies x = \frac{7\pi}{6},\ \frac{11\pi}{6}$
$\displaystyle \sin x = -1 \implies x = \frac{3\pi}{2}$
$\displaystyle x = \frac{7\pi}{6},\ \frac{3\pi}{2},\ \frac{11\pi}{6}$
#41Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle 2\sin^2 x + 5\sin x = 3$
Formula / idea used: Set equal to $0$, then factor like $2u^2 + 5u - 3 = (2u - 1)(u + 3)$. Zero-product property: if $AB = 0$, then $A = 0$ or $B = 0$.
Show steps and answer
$\displaystyle 2\sin^2 x + 5\sin x - 3 = 0 \implies (2\sin x - 1)(\sin x + 3) = 0$
$\displaystyle \sin x = \frac{1}{2} \implies x = \frac{\pi}{6},\ \frac{5\pi}{6}$

$\sin x = -3$ has no solution, because $-1 \le \sin x \le 1$.

$\displaystyle x = \frac{\pi}{6},\ \frac{5\pi}{6}$

Category 5: Multiple Angles

Solve for the inside angle over the stretched interval first, then divide.

Level 2

#53Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \sin 2x = -\frac{1}{\sqrt{2}}$
Formula / idea used: Multiple angle: if $0 \le x \le 2\pi$, then $0 \le nx \le 2n\pi$. Find every value of $nx$ first, then divide by $n$.
Show steps and answer
$\displaystyle -\frac{1}{\sqrt{2}} = -\frac{\sqrt{2}}{2}$

Since $0 \le x \le 2\pi$, the inside angle runs over $0 \le 2x \le 4\pi$ (2 revolutions).

Sine is negative in QIII and QIV; reference angle $\frac{\pi}{4}$.

$\displaystyle \text{1st revolution: } 2x = \frac{5\pi}{4},\ \frac{7\pi}{4}$
$\displaystyle \text{2nd revolution (+}2\pi\text{): } 2x = \frac{13\pi}{4},\ \frac{15\pi}{4}$
$\displaystyle \div 2: \quad x = \frac{5\pi}{8},\ \frac{7\pi}{8},\ \frac{13\pi}{8},\ \frac{15\pi}{8}$
$\displaystyle x = \frac{5\pi}{8},\ \frac{7\pi}{8},\ \frac{13\pi}{8},\ \frac{15\pi}{8}$
#54Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \cos 3x = 0$
Formula / idea used: Multiple angle: if $0 \le x \le 2\pi$, then $0 \le nx \le 2n\pi$. Find every value of $nx$ first, then divide by $n$.
Show steps and answer
$\displaystyle 0 \le 3x \le 6\pi \ (\text{3 revolutions}); \quad \cos\theta = 0 \text{ at } \theta = \frac{\pi}{2} + k\pi$
$\displaystyle 3x = \frac{\pi}{2},\ \frac{3\pi}{2},\ \frac{5\pi}{2},\ \frac{7\pi}{2},\ \frac{9\pi}{2},\ \frac{11\pi}{2}$
$\displaystyle \div 3: \quad x = \frac{\pi}{6},\ \frac{\pi}{2},\ \frac{5\pi}{6},\ \frac{7\pi}{6},\ \frac{3\pi}{2},\ \frac{11\pi}{6}$
$\displaystyle x = \frac{\pi}{6},\ \frac{\pi}{2},\ \frac{5\pi}{6},\ \frac{7\pi}{6},\ \frac{3\pi}{2},\ \frac{11\pi}{6}$
#55Level 2 (3 pts)
Solve on $[0, 2\pi]$:   $\displaystyle \sqrt{3}\tan 3x = 0$
Formula / idea used: Multiple angle: if $0 \le x \le 2\pi$, then $0 \le nx \le 2n\pi$. Find every value of $nx$ first, then divide by $n$. On the closed interval, the endpoint $6\pi$ counts.
Show steps and answer
$\displaystyle \tan 3x = 0; \qquad 0 \le 3x \le 6\pi; \quad \tan\theta = 0 \text{ at } \theta = k\pi$
$\displaystyle 3x = 0,\ \pi,\ 2\pi,\ 3\pi,\ 4\pi,\ 5\pi,\ 6\pi$
$\displaystyle \div 3: \quad x = 0,\ \frac{\pi}{3},\ \frac{2\pi}{3},\ \pi,\ \frac{4\pi}{3},\ \frac{5\pi}{3},\ 2\pi$
$\displaystyle x = 0,\ \frac{\pi}{3},\ \frac{2\pi}{3},\ \pi,\ \frac{4\pi}{3},\ \frac{5\pi}{3},\ 2\pi$
