🏛️ Pillar 1: General Inverses & Function Tables (Lesson 1)

Worksheet A Focus

Inverses swap domain and range: (x, y) → (y, x). A function has an inverse function if and only if it passes the Horizontal Line Test (one-to-one).

Key Composition Inversion Property:
(f ∘ g)−1(x) = (g−1 ∘ f−1)(x) = g−1(f−1(x))
Notice the order flips! Always evaluate the inner function first.
Evaluating Polynomial Inverses f−1(c):
  1. Set f(x) = c.
  2. Subtract c to set the equation equal to zero: f(x) − c = 0.
  3. Factor by grouping or synthetic division. (Remember: because polynomials can have multiple pre-images, f−1(c) can yield multiple values!)
Example from Worksheet A: If f(x) = x3 − 7x2 − 8x + 5, evaluate f−1(5).
x3 − 7x2 − 8x + 5 = 5 &implies; x(x2 − 7x − 8) = 0 &implies; x(x − 8)(x + 1) = 0
∴ f−1(5) = { 0, 8, −1 }

🏛️ Pillar 2: Arc Trig Strict Range Restrictions (Lesson 2)

Worksheet B Focus

Because trig functions are periodic, their domains were strictly restricted to define inverses. You MUST memorize these output boundaries:

Function Input Domain Strict Output Range (θ) Active Quadrants Critical Pitfall Alert
θ = arcsin(x) [−1, 1] [−π2, π2] Quadrants I & IV Negative angles MUST be written as negative acute (e.g. −π6), NEVER 11π6!
θ = arccos(x) [−1, 1] [0, π] Quadrants I & II Negative inputs produce obtuse angles in Quadrant II (e.g. 2π3, 3π4, 5π6).
θ = arctan(x) (−∞, ∞) (−π2, π2) Quadrants I & IV Open interval due to vertical asymptotes at ±π/2.
θ = arcsec(x) (−∞, −1] ∪ [1, ∞) [0, π], θ ≠ π2 Quadrants I & II Equal to arccos(1/x). arcsec(−2) = arccos(−1/2) = 2π3.
θ = arccsc(x) (−∞, −1] ∪ [1, ∞) [−π2, π2], θ ≠ 0 Quadrants I & IV Equal to arcsin(1/x). arccsc(√2) = arcsin(√22) = π4.
🚨 The #1 Mistake on Unit 3 Quizzes:
Evaluating arcsin(−1/2) as 11π6 or 7π6. In AP Precalculus, the range of arcsin is strictly [−π/2, π/2], so writing 11π/6 receives ZERO points. The ONLY correct answer is −π/6!

🏛️ Pillar 3: Composite Trig & Right Triangle Modeling (Lesson 3)

Videos 4, 5, 6
Rule A — Out-of-Bounds Cancellation:
arcsin(sin θ) = θ ONLY IF θ ∈ [−π/2, π/2].
If θ is outside this range, evaluate in 2 steps:
arcsin(sin(5π6)) &implies; sin(5π6) = 12 &implies; arcsin(12) = π6
arccos(cos(7π4)) &implies; cos(7π4) = √22 &implies; arccos(√22) = π4
Rule B — 4-Step Right Triangle Method for Variable Algebraic Composites:
  1. Let θ = inside arc function. For example, θ = arccos(2x).
  2. Write ratio: cos θ = 2x1 = AdjacentHypotenuse.
  3. Draw right triangle and use a2 + b2 = c2:
    Opposite = √(12 − (2x)2) = √(1 − 4x2).
  4. Evaluate outer function:
    tan(arccos(2x)) = OppositeAdjacent = √(1 − 4x2)2x

🧠 Trig Identities Memorization Bank (TD 23–25)

Daily Drill Formulas • 100% Required

Required for daily class drills starting Monday (9/21). Memorize every identity until you can write them out instantly from memory:

Double-Angle Formulas

sin(2θ) = 2 sin θ cos θ
cos(2θ) = cos²θ − sin²θ
cos(2θ) = 2cos²θ − 1
cos(2θ) = 1 − 2sin²θ
tan(2θ) =  2 tan θ1 − tan²θ

Sum & Difference Formulas

sin(u ± v) = sin u cos v ± cos u sin v
cos(u ± v) = cos u cos v ∓ sin u sin v
tan(u ± v) =  tan u ± tan v1 ∓ tan u tan v

Half-Angle Formulas

sin(u2) = ±√1 − cos u2
cos(u2) = ±√1 + cos u2
tan(u2) =  1 − cos usin u
tan(u2) =  sin u1 + cos u

Power-Reducing Formulas

sin²u =  1 − cos(2u)2
cos²u =  1 + cos(2u)2
tan²u =  1 − cos(2u)1 + cos(2u)

Q1: If g(x) = x3 + 3x2 − 4x − 10, evaluate g−1(2). ▼ Show Solution
Set g(x) = 2:
x3 + 3x2 − 4x − 10 = 2 &implies; x3 + 3x2 − 4x − 12 = 0
Factor by grouping:
x2(x + 3) − 4(x + 3) = 0 &implies; (x2 − 4)(x + 3) = 0 &implies; (x − 2)(x + 2)(x + 3) = 0
Answer: g−1(2) = { −3, −2, 2 }
Q2: Given (f ∘ g)−1(x) = (g−1 ∘ f−1)(x). If f(2) = 3 and g(3) = 2, find (f ∘ g)−1(3). ▼ Show Solution
Using property (f ∘ g)−1(3) = g−1(f−1(3)).
Since f(2) = 3, f−1(3) = 2.
Now evaluate g−1(2): since g(3) = 2, g−1(2) = 3.
Answer: 3
Q3: Evaluate arcsin(−√32) in exact radians. ▼ Show Solution
arcsin range is strictly [−π/2, π/2] (Quadrants I & IV).
Negative values MUST be written as negative acute angles in Quadrant IV.
Reference angle is π/3, so in QIV: −π3.
(Caution: Writing 5π/3 will receive ZERO credit!)
Q4: Evaluate arccos(−√22) in exact radians. ▼ Show Solution
arccos range is [0, π] (Quadrants I & II).
Negative inputs go into Quadrant II.
Reference angle is π/4 &implies; θ = π − π4 = 3π4.
Q5: Evaluate arcsec(−2) in exact radians. ▼ Show Solution
arcsec(−2) = arccos(−1/2) in Quadrant II.
Reference angle is π/3 &implies; θ = π − π3 = 2π3.
Q6: Evaluate arcsin(sin(5π6)). ▼ Show Solution
Notice 5π6 ∉ [−π/2, π/2], so the functions DO NOT simply cancel out!
Step 1: Evaluate inner function: sin(5π6) = 12.
Step 2: Evaluate outer function: arcsin(12) = π6.
Q7: Evaluate arccos(cos(−π3)). ▼ Show Solution
Step 1: cos(−π/3) = cos(π/3) = 12.
Step 2: arccos(1/2) = π3.
Q8: Evaluate tan(arccos(−513)). ▼ Show Solution
Let θ = arccos(−5/13) in Quadrant II.
In QII: Adjacent = −5, Hypotenuse = 13.
Opposite = √(132 − (−5)2) = √144 = 12 (positive in QII).
tan θ = OppositeAdjacent = 12−5 = −125.
Q9: Write sin(arccos(2x)) as an algebraic expression in x. ▼ Show Solution
Let θ = arccos(2x/1) &implies; cos θ = 2x1.
Adjacent = 2x, Hypotenuse = 1.
Opposite = √(12 − (2x)2) = √(1 − 4x2).
sin θ = OppositeHypotenuse = √(1 − 4x2).
Q10: Write tan(arcsin(x√(x2 + 25))) as an algebraic expression in x. ▼ Show Solution
Let θ = arcsin(x√(x2 + 25)).
Opposite = x, Hypotenuse = √(x2 + 25).
Adjacent = √([√(x2 + 25)]2 − x2) = √(x2 + 25 − x2) = √25 = 5.
tan θ = OppositeAdjacent = x5.
